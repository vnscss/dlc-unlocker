  O QUE É ISSO?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Ferramenta para baixar, extrair e instalar DLCs do The Sims 4
  no Linux. Tudo em três cliques, sem precisar abrir terminal.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  REQUISITOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  - Linux (Arch, Debian/Ubuntu, Fedora, openSUSE ou derivados)
  - Python 3.10 ou superior
  - The Sims 4 instalado via Steam
  - Conexão com a internet


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  INSTALAÇÃO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Abra o terminal na pasta do programa
  2. Execute o instalador de dependências:

       chmod +x install.sh
       ./install.sh

  3. Pronto. Para abrir o programa:

       python3 main.py


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  COMO USAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  PASSO 1 — BAIXAR
  ─────────────────
  • Clique em "⬇ Baixar" no DLC que quiser
  • O progresso aparece em tempo real com velocidade e tamanho
  • Você pode baixar vários ao mesmo tempo
  • Para cancelar um download, clique em "✕ Cancelar"
    (o arquivo parcial é mantido no disco)

  Os arquivos vão para a pasta configurada no topo da janela.
  Padrão: ~/Downloads/DLCs
  Você pode mudar clicando em "Alterar".


  PASSO 2 — EXTRAIR
  ──────────────────
  • Clique no botão "📦 Extrair" no topo da janela
  • O programa encontra todos os .zip na pasta de downloads
    e extrai automaticamente
  • Cada .zip vira uma pasta com o mesmo nome


  PASSO 3 — MOVER
  ────────────────
  • Clique no botão "📂 Mover" no topo da janela
  • O programa localiza o The Sims 4 automaticamente via Steam
  • Move os arquivos para os lugares certos dentro do jogo:
      → Pasta raiz do jogo  (arquivos EP**)
      → __Installer/DLC     (arquivos do instalador)
  • Se uma pasta já existir, o programa pergunta se quer substituir


  PASSO 4 — EA UNLOCKER
  ──────────────────────
  • Clique em "🛠 EA Unlocker" para abrir o gerenciador do unlocker
  • Selecione o prefixo do Wine onde o jogo está instalado
  • Clique em "Instalar / Atualizar" para aplicar o desbloqueio
  • Após instalar os DLCs, sempre rode o Unlocker novamente

  DICAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  • Use a barra de busca para filtrar por nome ou tag
    (ex: "EP05", "Expansion Pack", "KIT")

  • O catálogo de DLCs é atualizado automaticamente a cada
    abertura do programa — novos packs aparecem sem precisar
    reinstalar nada

  • Logs de uso ficam em: configs/dlc_unlocker.log
    Útil para debugar se algo der errado

  • Se a internet cair durante o download, cancele e recomece.
    O programa tenta reconectar automaticamente até 3 vezes
    antes de mostrar erro

  PROBLEMAS COMUNS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  "Link não disponível"
  → O DLC ainda não tem link cadastrado. Em breve!
  → Eu não desbloqueei o link

  "Sims 4 não encontrado"
  → Certifique-se de que o jogo está instalado via Steam.
    O programa procura nas pastas padrão do Steam no Linux.
    possiveis problemas com steam instaladas por fonte como flatpak, snap ou .deb do site da steam, para resolver instale a steam corretamente! 
    pela distribuição padrão de pkg da sua distro.

  "zip corrompido"
  → O download foi interrompido ou o arquivo está incompleto.
    Delete o .zip e baixe novamente.

  "libtorrent não encontrado" #não é mais necessario, erro não vai aparecer para você
  → Rode ./install.sh novamente.

  Qualquer outro erro: abra uma issue no GitHub ou me chama
  nas redes sociais abaixo.
